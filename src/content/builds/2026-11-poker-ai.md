## What it does

I’m building a poker AI with counterfactual regret minimization (CFR). I started with regret matching on rock-paper-scissors, then implemented a Kuhn poker trainer. I wrote it from scratch in Python using only the standard library.

## First milestone

My first milestone is done. The Kuhn poker trainer reaches a game value close to the theoretical value of −1/18.
